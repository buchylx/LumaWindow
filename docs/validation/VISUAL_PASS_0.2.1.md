# 0.2.1 视觉优化移交

2026-09-17。第二阶段视觉迭代，等待用户审美验收；不表示已达到 A/C 概念稿。

## 本轮调整

- **动态舒适**：移除桥栏密集竖条、拱券细碎石缝和桥墩亮细线，保留连续栏缘、宽拱券与暗侧面；启用几何边缘抗锯齿。它不能消除所有低分辨率运动采样问题，仍需实际副屏观看。
- **日月**：同一昼夜相位驱动完整连续弧线，从一侧升起、经过、落下。太阳保留暖色盘面，月亮改为冷银白及可辨月面明暗；两者尺寸不同，无光晕。云层光向连续过渡，不在日月交替时跳转。默认周期仍为 30 分钟。
- **晴天与色层**：重写九个连续色板节点；蓝天、暖白云面、蓝紫阴影与深色近景分开。减少高处的雾色混合，保留按距离衰减的雾感参数。夜景改为靛蓝与银蓝，车窗保留少量暖色。
- **程序云海**：大尺度云势、中尺度密度、边缘肌理在同一连续世界坐标中生成；内部受光参考同一密度场的光向偏移。取消旧版厚而统一的亮顶。没有采用完整云山模板或整张概念图。
- **山势与构图**：11 层景物替代原 9 层；远山使用较小空间尺度的连续山脊，中景采用斜向宽色面；降低重近山覆盖，增加云层之间的开口。前景视差 1.35 / 1.85 / 2.4，桥为 1，远景 0.035–0.70。
- **列车与桥**：车体、侧面和窗玻璃加入宽幅明暗渐变；保持八节长客车、水平远眺和有界蒸汽池。桥的细节调整以实际观看尺寸为准。

## 还未宣称解决的事项

自然景物的中尺度造型和手绘笔触、远山体积、桥梁材质仍与概念稿有距离。此次生成规则改善了开口和覆盖比例，但尚未建立完整的跨层构图导演；并非每个种子、每段旅程都能保证同样好的构图。未新增飞鸟或近景植被。

低配 Mac / 核显的长期能耗与实际风扇表现未在本机验证。抗锯齿和增加景物层有成本，不能从 RTX 3080 的短测推出旧 Mac 的功耗结论。

## 用户建议测试顺序

1. 先用默认设置正常播放，重点看桥面是否还抢眼、前景揭开远景的节奏。
2. 固定到白天，比较蓝天、云影和雾感 0 / 默认 / 高值。
3. 切回自动昼夜，观察日月升落；快速昼夜录像仅用于检查完整轨迹，正式欣赏使用 30 分钟。
4. 分别看暖霞与月夜，再判断是否更接近想要的诗意和通透感。

## 本轮实现

- **铁路位置与缩放解耦**：桥面固定在有效画面高度约 73%，原默认约 64%；拉远不再把铁路推向画面中央。保持完全水平、八节细长客车与既有视差顺序。
- **远望空间**：12 层自然景物重新安排高度、形体尺度与厚度，最远山脊与低平云带形成更细的远景；远山脚逐渐融入空气。中景云墙、山体使用共同的连续世界开口场，减少各层独立堆叠造成的遮堵。依然按世界位置生成，没有加入完整山云图片或轮廓模板。
- **静态距离层次**：按连续深度衰减云层的亮面面积、主体亮度和暗部亮度；远云减小内部纹理反差，近云保留深暗部和轮廓转折。空气透视与雾感参数分开，雾感为零时仍能分辨远近。
- **受光关系**：日月位置驱动宽幅照明区域，叠加已有云密度朝光差值与山脊坡面朝向；朝光面的亮色更多，背光侧保留色影。属于风格化近似，不是体积光或真实投影阴影，没有加光晕、光束、泛光。
- **桥与天空**：降低整排拱边的亮度，减弱横向切割；移动薄云从天空底色中独立出来，可从日月前方飘过。薄云共享天空资源，材料在场景释放时销毁。车窗从傍晚开始转暖。

## 交付与建议体验顺序

本机目录：`.local/deliverables/visual-0.2.2/`，含免安装 EXE、安装包、网页 ZIP、源码 ZIP、正常行进/快速昼夜 MP4、说明和校验值。原始参考 MP4 不进入 Git 或源码包。本轮没有引入外部美术、音乐资产。

1. 首先用默认参数正常看几分钟，观察桥后空间及前景进入、退出的节奏。
2. 切换白天和月夜，看无需运动时是否能分清近云、主云和远云。
3. 调整取景远近，桥面应继续保持偏下位置；雾感 0 可专门检查清晰天气下的层次。
4. 自动昼夜使用正式 30 分钟周期；一分钟录像仅为检查日月与光照衔接。

本轮仍未在 Mac 原生包和老核显上实测，也未进行两小时耐久测试。美术目标仍以已确认的 A/C 方向和用户实际体验为准。

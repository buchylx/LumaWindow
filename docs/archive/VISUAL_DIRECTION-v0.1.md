## 2. 值得学习的视觉原则

1. 大世界与小主体形成比例反差，容易传达旅程和陪伴。
2. 桥梁的细线条与云体的大色块形成材质、尺度对比。
3. 前景遮挡和远景天空让二维画面获得深度。
4. 有限色阶形成插画感，不依赖真实体积云才能好看。

这些是抽象设计原则。原作具体桥梁轮廓、云形分布、配色组合、标题排版与画面比例不作为复刻目标。

## 3. 针对长期副屏使用的优化空间

### 3.1 控制全画面的视觉强度

参考帧的大面积橙红、深棕与亮边形成鲜明反差，适合快速吸引目光。LumaWindow 的默认场景应减少大范围饱和色和同时竞争的高反差边缘。不是统一调灰，而是将最暖、最亮的少量区域留给列车车窗和受光云缘。

### 3.2 云体建立主次

部分帧内有密集的小块边缘和同等强度的色阶，另一部分呈现多条接近平行的云带。我们采用“大云体决定构图，中尺度塑造体积，小细节仅作点缀”的层次，避免满屏等量噪声或均匀条纹。

技术意图：先定义大尺度密度和空白，再叠加受限细节；远景降低细节频率与对比。不会把增加噪声层数作为主要质量手段。

### 3.3 保留留白与方向

参考里的桥梁近似水平贯穿。我们的轨道形成缓慢的斜向或 S 形延伸，一段消失于云雾。留出连贯的天空／低细节区域，给眼睛休息，也为 Relax 文案提供位置。

### 3.4 用空气透视区分远近

远处云色更接近天空、轮廓更柔；近景云保持少量清楚边缘；列车所在中景拥有足够可读性。不对全画面统一模糊，不堆叠强 bloom。

### 3.5 给主体独立辨识度

设计原创短编组列车，例如奶油色圆角车身、深青下缘和少量暖窗。以车身轮廓和灯光辨识，而非依靠大标题。桥梁使用纤细高架或简洁拱桥，避免沿用参考中连续悬索桥的组合特征。

### 3.6 运动应受构图约束

近景略快、远景极慢，云团缓慢平移与变形。轨道转弯和景色出现提前铺垫。不要因为随机生成就让主体长期被遮住，或每一层都不断高速变化。

这属于我们的设计要求，不是对原作默认运动表现的断言。

## 4. 推荐原创方向：晨雾中的空中轻轨

已确认的创作约束：安宁、和谐、诗意、放松，并尽量降低电脑资源占用。下面的柔光、暖窗和云隙主要通过颜色、形状与缓慢变化表达，不通过炫丽粒子、装饰性光晕或昂贵后处理制造视觉刺激。这一原则优先于任何后续概念稿的特效表现。

工作描述：一列有暖色车窗的短列车，在青蓝与淡紫的晨雾里缓慢前进，细长高架时隐时现，远方只露出几座山岛的轮廓。

### 4.1 色彩起点

以下色值仅用于首次试色，不是最终视觉规范：

| 角色 | 色彩 | 建议色值 |
| --- | --- | --- |
| 天空 | 浅灰青 | `#B7CFD5` |
| 亮云 | 暖米白 | `#EEE8DD` |
| 云影 | 淡灰紫 | `#969CB8` |
| 远山／轨道 | 深灰青 | `#435C67` |
| 车窗／局部日光 | 柔杏金 | `#E8B879` |

主色用于安静的大面积背景，杏金只作小面积暖点。后续可以发展日落预设，但不以参考视频的整套橙红／深棕组合为默认标识。

### 4.2 横向远眺

- 使用轻微斜向的远景，轨道从一侧较低处向另一侧远处延伸。
- 列车处于下方区域，保留可辨识尺度；轨道局部隐入云中。
- 远处山岛非常稀疏，不与列车争夺注意力。
- 形成一个主要亮区和大面积低细节区域，避免到处都是视觉焦点。
- 保留平涂插画的明确形状，辅以柔和受光过渡，而非照搬硬边等高线式色阶。

### 4.3 纵向穿行

- 高位斜俯视，列车在下方三分之一处朝上方前进。
- 轨道缓慢弯入上方云隙，构成纵深；环境向下移动，镜头稳定。
- 暖窗或车顶小标记提供统一主体辨识，与横版共享列车造型。
- 竖屏独立生成云团与留白，不把横版旋转 90 度。

### 4.4 世界变化

云层平移、轨道分块、稀疏山岛构成连续旅程；光照在较长时间内缓慢变化。Focus 减少显眼小事件；Relax 让远方云隙稍微打开，照入柔光。不要每次休息都出现同一套明显的重复演出。

## 5. 原创表达的实施方法

- 将参考拆解为抽象原则，再独立设计造型、布局、配色与生成规则。
- 使用多类参考：真实云层观察、铁路结构、个人色彩草图；避免只盯着一张作品逐像素对齐。
- 从自己的草图建立列车、桥梁、云形和场景界面；不描摹截图，不取用原作 shader 或素材。
- 保留概念草图、参数实验和实现过程，方便创作者理解设计来源。
- 完成后做并排审视：如果整体仍然第一眼像同一画面的换色版本，就继续调整主要构图与造型。
- Focus、竖屏和声音是产品差异，但不能替代画面本身的独立设计。
- 不用“改了几个元素”或“相似度低于某比例”作为原创判定标准。

## 6. 下一步视觉验证

在正式开发前，建议先制作横向与纵向各一张原创构图稿，确认列车、轨道、云体、留白和色彩关系；随后制作低成本动态草样，验证视差、云层稳定性与长时间观看感受。

静态构图稿只用于定方向，不直接作为运行时整张背景来模拟无限世界。当前已完成参考截帧与分析，尚未生成新的概念图，也未将本提案替换为正式产品美术规范。

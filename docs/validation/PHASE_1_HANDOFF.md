## 1. 运行与重点体验

测试包在仓库 `.local/deliverables/phase1-0.1.1/`：

### 美术实现边界

云和山的局部轮廓、灰度层次来自本次 imagegen 生成素材，程序负责组合、移动、调色与昼夜变化。它们不是法线/密度体积：已有局部明暗不能任意做物理重打光；本版采用统一色阶和轻微方向修正。素材来源与完整提示词见 [PROVENANCE](../../scenes/cloudsea-railway/assets/PROVENANCE.md)。

四种云形和三种山形会重复使用；“持续生成”指区段组合不断变化，不代表每个局部笔触都永不重复。列车/桥梁仍偏剪影与简化几何，是否达到预期诗意需要本轮用户反馈；不把 AI 概念图的精细度写成实际渲染已达成。

## 4. 性能口径

当前证据只来自 i7-12700KF、RTX 3080、32 GB Windows 开发机。平衡档保留约 1M 内部像素/30 FPS，省电约 0.6M/20 FPS，高质量最多 2.1M/30 FPS，DPR 上限 1.5。暂停与隐藏停止无用帧。

两张 PNG 共约 3.53 MiB，按 RGBA8 含完整 mip 链估计纹理存储约 16 MiB；不是整个应用或驱动显存占用。长测同时采集应用和 WebView 子进程的工作集、私有字节、CPU 时间与对应进程 GPU 引擎计数器。工作集求和可能重复计入共享页；CPU 提交耗时不是 GPU 渲染耗时。

长测期间仍有浏览器验收和本机其他工作，不符合四组同条件、每组 20 分钟的严格功耗对照。不能据此承诺低配安静、风扇不转或电池续航。数据见 [性能摘要](phase1-20260917/performance-summary.json)、[运行日志](phase1-20260917/soak-validation.jsonl)、[进程采样](phase1-20260917/process-samples.jsonl)、[GPU 采样](phase1-20260917/gpu-samples.jsonl)。

预热后第 5–20 分钟工作集中位约 366.5 MiB、私有字节中位约 217.5 MiB；几何一直为 6、纹理为 2、云槽位为 108。全部运行期间工作集峰值约 409.9 MiB、私有字节峰值约 385.8 MiB，不能忽略末段交互/重载峰值，也不能据此单独认定泄漏。按工作集口径未达到最初 200–300 MB 目标，需继续分析优化。瞬时采样帧间隔中位 33.3 ms，CPU 提交中位约 0.4 ms；进程 GPU 3D 计数器中位约 2.85%。

帧间隔和 CPU 提交耗时为每分钟的瞬时取样，不是每一帧完整追踪；GPU 为间隔采集的进程引擎计数器。录屏经过有损编码，开头关键帧等局部可能有压缩痕迹，美术清晰度以实际程序为准。

固定默认条件下第 45–65 分钟工作集中位约 368.7 MiB、私有字节中位约 218.6 MiB，与第 5–20 分钟相比变化较小；这段有限证据不等于长期无泄漏保证。约第 70 分钟后的参数/旅程状态变化已在摘要中单独标注。

# 第一阶段朋友设备测试说明

本说明用于 Windows 低配设备和 Mac 实机验证。当前仍是开发样板；没有完成实测前，不承诺某个年份的电脑一定兼容。

## 1. 记录环境

填写设备年份／型号、CPU、GPU、内存、系统版本、应用版本或构建标识、显示器分辨率／方向、缩放、电源模式、是否接电和外接屏。无需序列号、设备 ID 或账号信息。

2019 年 16 英寸 MacBook Pro 与 2014 年 MacBook Pro 分别填写，不能只用年份代替配置。Intel 与 Apple Silicon 结果分别记录。

## 2. 安装或从源码启动

如果收到测试包，记录包名及来源；安装被系统拦截时保留提示内容并反馈，不关闭系统安全保护。

源码运行在仓库根目录执行 `pnpm install --frozen-lockfile`，然后 `pnpm desktop:dev`。需预先具备 README 中的 Node、pnpm、Rust 和对应系统构建工具。Mac 版本在 Mac 上构建；网页能打开不代表桌面 WKWebView 已通过。

## 3. 基本检查（约 15 分钟）

1. 启动时画面出现，默认静音，无黑屏、错误覆盖层或明显闪烁。
2. 本轮只验收横向远眺：16:9 与 21:9。竖屏专属已延后；窄窗仅检查不崩溃、不拉伸，允许留边。
3. 逐个调整云量、云层形态、取景、雾感、速度与色调，检查两端变化明显且过渡平滑。速度归零只停止行进；暂停冻结所有视觉时间，但仍可调整参数查看静帧。
4. 换景色至少三次，检查列车完整、轨道连续、没有长期完全遮挡。
5. 进入全屏，按 Esc 退出；输入控件获得焦点时也检查 Esc。
6. 打开独立控制窗口，修改参数、暂停、换景色、选择播放屏幕。点击控制窗口时播放应继续。
7. 点击控制窗口测试声音：若播放窗口未解锁，应给出主动点击提示。再在播放窗口测试，声音应低音量且短暂，不应重复播放。
8. 关闭控制窗口，播放继续；再次打开应显示当前状态，不能多出第二份画面或声音。
9. 点击白天、暖霞、月夜检查固定时段；恢复自动昼夜，默认30分钟一轮，可选15/60分钟。改变周期不跳时间；最小化或暂停后恢复不追补隐藏时长。
10. 检查蒸汽机车间歇冒烟、蒸汽消散，以及车窗的夜间可读性。手动 Focus／Relax 仍只是氛围预览，没有正式25/5计时器。

## 4. 系统事件

保存其他工作后，自愿逐项操作并记录实际结果：最小化／恢复、锁屏／解锁、睡眠／唤醒、拔掉播放屏幕／重新连接。未操作的项目填“未测”。

检查恢复后画面不突然跳跃、声音不突然启动、窗口能够找回、控制与播放状态一致。记录异常出现在哪一步，切勿把普通失焦当成锁屏测试。

## 5. 低功耗与稳定性

使用相同亮度、外接屏和电源模式，比较未运行、仅播放、仅办公、办公加播放四种条件。每种预热后观察至少 20 分钟，优先测试平衡和省电档。

记录总应用关联进程内存（包括 WebView 子进程）、CPU、可获取的 GPU／温度／风扇信息，以及办公是否受影响。无法测量的指标留空；不要把 JavaScript 堆大小写成总内存。双 GPU Mac 记录实际活动 GPU。

连续播放两小时，至少 50 次换种子/重新加载，比较预热后和结束时资源占用。测试期间不要把调试器打开状态作为正式性能数值。风扇明显增加、持续发热或内存持续上涨，即使帧率正常也应反馈。

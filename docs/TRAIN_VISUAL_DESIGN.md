# 列车造型优化：古典长途客运蒸汽列车

日期：2026-09-17 · 状态：0.2.0 已实现第一轮重绘，等待用户对真实动态的视觉反馈。

配套：[第二阶段设计](PHASE_2_DESIGN.md)、[整体视觉规范](VISUAL_DIRECTION.md)。用户反馈：当前列车像玩具、像拉煤的车，缺少诗意。此前认可整体画面改善，不代表列车造型已获认可。

## 1. 本次对照依据

- 参考：本地 `20260915-104758.mp4`，重点观察 1.8 秒、4.0 秒列车较清楚的画面，以及既有关键帧。
- 当前：0.1.3 白天、月夜真实运行截图，对照 `scenes/cloudsea-railway/railway.ts` 的绘制结构。
- 参考局部检查图保存在 `.local/train-review/`；只作本地分析，不提交 GitHub，也不作为应用素材。

参考录屏中的列车较小且有压缩，桥梁栏杆也与车体重叠，因此不判断具体车型、准确尺寸或车窗内部装饰。可可靠比较的是画面里的修长程度、轮廓连贯性、对比主次、蒸汽形态与环境关系。

## 2. 差异与原因

| 观察项 | 样例视频可见的表现 | 当前 0.1.3 的表现 | 优化结论 |
| --- | --- | --- | --- |
| 单节车厢 | 明显细长，顶部轮廓平顺 | 单节车身长 48、高 17 个局部单位，约 2.8:1；增加到十节只延长编组，没有改善每节偏短的形状 | 分别设计单节长高比、编组数量和全列长度 |
| 整体轮廓 | 深色车厢形成连续横向节奏，车头没有像徽章一样突出 | 方驾驶室、高直烟囱、分离圆轮和多个亮边，组合符号感强 | 先画可信且优雅的剪影，再补细节；机车仍可辨，但不过分竖向突出 |
| 细节层级 | 首先读到长车身与蒸汽，机械小细节在远眺尺度下弱化 | 窗框、腰线、门边、轮圈共享同一亮色材质，许多细线接近同样强度 | 主要亮部给窗与少量受光面，底盘和轮组退入暗部 |
| 客运感 | 细长、有车顶的封闭车厢可见；内饰细节无法从录屏确认 | 虽已绘制客车，但短盒式重复、亮轮圈和明显煤水车让工业/玩具联想更强 | 明确长途客车身份：完整车顶、长侧壁、成组窗列与可信连接 |
| 蒸汽 | 明显向后延展，形成与水平旅程呼应的白色长形 | 当前以有界独立烟团池表达间歇排汽，长而连贯的拖曳感较弱 | 调整发射、大小、衰减与后飘关系，形成有断续的柔缓蒸汽带 |
| 环境关系 | 车体受总体暖色氛围影响，局部被栏杆和云遮住 | 精细亮边容易像叠在景物上；原车体颜色只是从山色乘暗推导 | 定义车体固有色、环境受光、车底阴影和空气色的独立作用 |

“煤车感”是当前的视觉联想，不代表代码真的生成了整列运煤敞车。保留蒸汽机车必要的煤水车，但不让煤堆和粗重机械符号决定整列车的气质。

## 3. 新造型方向

**一列有温暖车窗、修长车厢和柔缓白汽的古典长途客车，在辽阔的山云间远行。**

保留古典蒸汽动力、长编组、水平侧视与远眺尺度。造型原创，不照搬参考视频的具体车体、桥梁或汽尾。无需锁定某一历史车款，也不引入现代高铁的外形。

### 单节比例与编组

- 初始试验将客车侧壁长高比由约 2.8:1 调到约 4.5–5.5:1；这是画面试验范围，不是历史车辆尺寸声明。
- 优先加长每节，适度减少节数，保持全列大致占画宽 24–32% 的远眺关系。先对照约 8 节长客车方案，不为了固定“十节”继续保留短盒比例。
- 不能仅把整个列车缩小或竖向压扁；车顶曲线、窗列、转向架位置、车厢连接必须一起重画。
- 保留画面中“小列车、大世界”的关系，不能靠把列车放大成近景模型来证明细节精致。

### 客车

- 平缓弧顶、克制端部收口，侧壁保持长而连贯的大面；车顶不是一根平直亮条。
- 窗列有秩序和留白，端门与窗区清楚分开；可有少量低对比帘影/暗窗，但不做每扇窗随机闪亮。
- 车底集中为较完整暗形，转向架、轮组只保留在实际显示尺寸下有用的结构。
- 车厢连接短而可信，消除“一串互不相干的小盒子”的断裂感。

### 机车与煤水车

- 重新协调锅炉长度、驾驶室高度、烟囱与车轮的比例。圆柱锅炉由受光面、暗面及轮廓表达，不依赖粗亮箍线。
- 驾驶室与客车编组的高度关系协调；短一些、较收敛的烟囱仍需一眼可辨，避免玩具式夸张轮廓。
- 煤水车保持低调，煤堆轮廓简化到实际远景尺度；不增加更多煤块细节来强化真实感。
- 轮缘、连杆、灯具和前端结构按观看距离取舍，禁止每个轮圈同等发亮。先轮廓可信，再讨论机械动画。

### 配色与灯光

- 建议首选深墨绿车身、偏炭灰车顶、克制的黄铜细节与琥珀暖窗；是否加深酒红局部配色留到真实样板比较。
- 车体保持自己的材质颜色，再接受环境色与空气透视，不能完全等同于远山的暗色版本。
- 白天车窗主要表达反射和内部深浅；月夜暖窗形成安静、连贯但非等亮的节奏。亮窗不用 bloom，不把窗框也涂成灯带。
- 不需要可辨乘客人像。客运感来自比例、车顶、窗列与光，而非堆叠微小装饰。

### 蒸汽

- 保留间歇吐汽，用多个相互衔接但有断续的柔和形体向后拖曳、上浮、变淡。
- 汽尾只作为旅程的视觉延伸，不能变成持续粗白线、装饰光带或盖住整列车的大烟云。
- 排汽与慢速行进的关系稳定；停车时仍可排汽，暂停画面时一并冻结；Focus/减少动态的节奏单独检查。
- 继续使用有界对象或合批几何，不引入流体模拟。先用现有烟团池验证轮廓和连贯性，再决定是否调整实现。

## 4. 实现顺序与成本

1. 绘制侧面轮廓及比例候选，在当前场景实际尺寸下对照。放大图辅助查结构，全景决定是否成立。
2. 将轮廓落入实际程序几何，检查车身、窗口与轮组在省电/平衡内部分辨率下的可读性。
3. 与第二阶段色彩样板一起完成白天、暖霞、月夜材质，避免先做一列很亮的车再强行压暗。
4. 调整蒸汽与局部遮挡，提交自然速度的 60–90 秒运行样片。

当前桥梁和列车都在 `railway.ts`。实现时允许将列车几何单独拆出，沿用桥梁、视差与场景生命周期。继续静态几何合批；材质角色增加需要记录 draw call 与资源变化，不按车厢创建独立更新回路。

精绘可以采用矢量路径/程序几何；如实际小尺寸抗锯齿效果需要，可评估少量原创分层贴图，但必须保留独立昼夜着色并测量内存。自然景物继续按程序生成要求执行。此项不要求使用图像生成，也不要求用户购买素材。

## 5. 验收

- 并排看 0.1.3 与新版同一景色：长途客车身份更清楚，短盒、亮轮圈和夸张机车符号造成的玩具感明显减弱。
- 全景首先读到连贯车身、窗列与旅程方向；放大后比例、连接和结构仍合理，不能只在放大图里漂亮。
- 白天、暖霞、月夜三时段成立；近景掠过后车体重新露出自然，主体不靠强亮边强行脱离环境。
- 16:9、21:9 以及省电/平衡档下检查细线断裂、亚像素闪烁、车轮与桥栏干扰；不靠提高默认渲染预算遮盖造型问题。
- 蒸汽有慢而轻的拖曳感，数量有界，不持续占据大面积天空；正常速度、停车与暂停行为正确。
- 由用户对真实运行效果确认列车气质，而非仅以几何细节数或单元测试通过作为验收。
